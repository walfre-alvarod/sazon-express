# Entregas por fases

Esta carpeta organiza la evidencia del desarrollo de Sazon Express segun el cronograma del proyecto. El codigo fuente se mantiene una sola vez en la raiz del repositorio para que la aplicacion pueda ejecutarse sin cambiar rutas ni duplicar archivos.

| Fase | Periodo | Entrega principal | Estado |
| --- | --- | --- | --- |
| [Fase 1](fase-1/README.md) | 31 ago - 15 sep | Diseno UI/UX y modelo relacional | Completada |
| [Fase 2](fase-2/README.md) | 16 sep - 30 sep | Servidor, MySQL y API REST | Completada |
| [Fase 3](fase-3/README.md) | 1 oct - 18 oct | Consumo de API, carrito y formularios | Completada |
| [Fase 4](fase-4/README.md) | 19 oct - 25 oct | Pruebas integrales y refinamiento | Completada |
| [Fase 5](fase-5/README.md) | 26 oct - 29 oct | Documentacion y entrega final | Completada |

## Proyecto ejecutable

- [`frontend/`](../frontend/): tienda, carrito, checkout, seguimiento y administracion.
- [`backend/`](../backend/): servidor Express, API REST y acceso a MySQL.
- [`database/`](../database/): esquema, migraciones y actualizacion de datos.
- [`test/`](../test/): pruebas automaticas.
- [`README.md`](../README.md): instalacion, ejecucion y recorrido de prueba.
